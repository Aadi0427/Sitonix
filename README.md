# Sitonix

> **Sitonix** is a modern web development agency focused on building professional, responsive, and performance-oriented digital experiences.

## 🌐 Overview

Sitonix is a static agency website created to showcase the company's services, projects, testimonials, FAQs, and contact options through a modern dark-themed interface.

## ✨ Features

- Responsive navigation with mobile menu
- Hero section with clear CTAs
- About Sitonix section
- Web Development services
- UI/UX Design services
- SEO & Marketing services
- Website Maintenance
- Featured projects section
- Client testimonials
- FAQ accordion
- Contact form
- Contact modal
- Google Maps integration
- WhatsApp contact button
- Responsive hero artwork
- Scroll animations
- SEO metadata and Organization structured data

## 🛠️ Tech Stack

- **HTML5**
- **Tailwind CSS**
- **CSS3**
- **Vanilla JavaScript**
- **AOS (Animate On Scroll)**
- **Formspree**
- **Google Maps Embed**
